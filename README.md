# 二进制格式版本工作台（binfmt-workbench）

单机运行的二进制文件格式多版本解析 / 迁移工作台。**所有规则都在服务端执行并用
SQLite 持久化数据驱动；网页只是规则的可见入口。**

## 快速开始

```sh
cargo fetch
cargo test --quiet
cargo run --bin server -- --listen 127.0.0.1:5219
```

打开 <http://127.0.0.1:5219>。默认数据库为当前目录的 `workbench.db`，可用
`--db <path>` 指定（建议验收时用一次性路径，便于重复运行）。

## 它能做什么

- **结构化声明格式**：magic、整数（1/2/4/8/16 字节，大小端、有符号）、定长
  字节、动态长度字节、对齐填充（zero/raw）、位域、结构体、条件分支、标量/定长
  结构体数组、TLV 扩展容器、校验字段。
- **按版本解析并保留未识别区域**：未识别 TLV 块、尾部多余字节都以原始字节
  保留在解析树里；解析成功后**未做任何修改直接写回，逐字节一致**，未知扩展
  保持原始顺序，绝不为方便而重排。
- **准确偏移报告**：短读、长度越界、字段重叠、重复扩展 tag、校验范围自指等
  错误都带输入字节偏移。
- **版本化迁移规则**：copy / constant / drop / 从扩展提升字段，支持
  `u16_to_u32`、`bytes_truncate_n`、`bytes_pad_n_xx` 等变换。对样本集做
  dry-run，输出字段来源、默认值、损失、输出布局与逐样本结果。
- **反向验证三档**：`strict`（重新表达后与原字节一致）、`semantic`（逻辑值
  一致，但校验/填充/宽度/常量等造成字节差异）、`lossy`（信息丢失）。接受
  lossy 项时把 **字段 × 规则修订号** 一起绑定。
- **继承**：定义可继承旧版字段（父版本被钉住修订号）；**循环继承与同名字段
  遮蔽一律拒绝**。
- **迁移计划**：draft → frozen → published → retired（frozen 可退回 draft）。
  冻结时固化定义指纹，并要求所有 lossy 项已被接受；非法状态跳转和落后修订号
  都被拒绝，落后写入返回双方字段级差异而不是静默覆盖。
- **批量转换原子化**：先在内存中转换全部文件，**任一文件失败就不创建任何可见
  批次**，响应里列出每个失败样本；全部成功才在一个事务里落库。
- **确定性导出**：`GET /api/export.tar` 产出无时间戳、路径排序、固定 uid/gid/
  权限的 USTAR，内含 `MANIFEST.sha256`；同一数据库内容导出逐字节一致。

## 架构取舍

- **单体 Rust crate（lib + `server` 二进制）**：规则引擎、解析器、迁移器全部
  在 `src/` 内，HTTP 层 (`src/http.rs`) 只做参数编排，因此规则不可能被前端绕过。
- **SQLite（rusqlite bundled）+ WAL**：零外部依赖、事务即崩溃边界。定义/规则/
  样本为**只追加**：每次保存产生新修订行，原文永不覆盖；样本原始字节存
  BLOB，任何“规范化”都只能另存新版本。
- **乐观并发**：所有更新带 `base_revision` / 计划 `revision`；服务端比对当前
  修订，冲突返回 `409` 与 JSON 字段级 diff（双方文档 + 差异路径）。
- **幂等**：写接口读取 `Idempotency-Key` 头并持久化响应，重复请求重放同一结果，
  不会产生重复修订、重复样本或重复批次。
- **身份写回不是“重新序列化”**：身份写回复用解析树叶子节点覆盖到的**原始字节
  区间**，因此天然保留未知扩展、非零 raw 填充和所有未识别内容，并在内部校验
  “输出 == 输入”，不一致即报错（这是一个正确性断言，而非兜底）。
- **校验和**：`sum8` / `xor8` / `crc32`(zlib) / `crc32c`(Castagnoli)，范围用
  表达式（支持 `$pos`/`$eof` 与排除区间）；字段自身字节落入覆盖范围且未被
  排除时报告 `checksum_self_reference` 及偏移。迁移输出时校验和按目标布局
  重新计算。
- **表达式语言**：`src/expr.rs` 是一个小型递归下降解析器（算术/位/比较/逻辑
  运算、点路径、`arr[3].x` 下标、`len(path)`、`$pos`、`$eof`），解析期与迁移
  期共用，避免两套语义。

## 数据模型（SQLite）

`defs`（name+revision 唯一，存规范 JSON 与指纹）、`rules`（同构版本化）、
`samples`（不可变 BLOB + sha256）、`plans`（状态机、冻结指纹、接受绑定、
dry-run 快照）、`batches` / `outputs`（completed 才可见）、`idempotency`、
`audit_log`。启动时执行崩溃恢复：所有遗留 `running` 批次标记为
`aborted_crash`（其输出仅作取证，不列入可见批次），恢复幂等。

## 主要 HTTP 接口

- `GET/POST /api/defs`，`GET /api/defs/{name}/{rev}`，`.../validate`
- `GET/POST /api/samples`，`GET /api/samples/{id}/bytes`
- `GET /api/parse?name&revision&sample=|hex=`（返回结构树、问题、标量图、
  身份写回 hex 及是否逐字节一致）
- `GET/POST /api/rules`，`.../validate`，`POST /api/dryrun`
- `GET/POST /api/plans`，`POST /api/plans/{id}/transition`
- `GET/POST /api/batches`，`GET /api/export.tar`

写接口接受 JSON，重复请求请带同一 `Idempotency-Key`。

## 页面

四个标签页：格式定义（JSON 编辑 + 校验 + 继承展开预览）、样本与解析（导入、
十六进制覆盖图、结构树、点击字段看读取/写出范围、双版本差异）、迁移规则
（编辑/校验/dry-run 报告与三档反向验证）、计划与批次（创建、冻结、接受 lossy
绑定、发布、退役、批量转换）。

## 测试

- `tests/parser.rs`：表达式引擎、身份写回字节一致、短读/越界/magic/校验自指/
  重复 tag 的准确偏移、TLV 已知与未知扩展保留、继承遮蔽/循环、迁移与反向分档、
  位域重叠、tar 确定性。
- `tests/server.rs`：重复请求（幂等键）、落后修订 409 差异、继承展开与遮蔽
  拒绝、解析身份一致、**非法状态跳转**、lossy 冻结门禁、批次部分失败不产生
  可见批次、导出确定性。
- `tests/recovery.rs`：用白盒方式注入 `running` 批次后重开数据库，验证
  **进程异常退出后的恢复**、已完成批次持久化、失败不留输出、跨重开确定性导出。

## 已知限制

- 数组元素只支持标量与**定长**结构体（动态长度元素在保存校验阶段被拒绝）；
  动态长度用顶层 `bytes length=expr` 表达。
- 顶层字段以顺序布局为主；同一作用域内的重叠检测覆盖标量叶子、字节、扩展块
  （含重复 tag）。位域成员重叠在校验阶段单独检查。
- 扩展块跨格式保留要求目标容器的 tag/长度宽度与顺序兼容；“从扩展提升字段”
  按容器名.扩展名.字段名寻址，反向只判定到 semantic（不重建被提升块）。
- 表达式为整数运算；`bytes` 值通过 `len(...)` 参与长度表达式。
- 页面为零构建的原生 JS 单页，超大样本的十六进制视图未做虚拟滚动（建议单样本
  在数百 KB 以内）。
